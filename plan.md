# План разработки личного планировщика

План основан на `tz.md`. В этом файле также ведется история разработки по шагам.

## Шаг 1. Каркас проекта и базовый интерфейс - сделан

### Готовый результат

Созданы три файла проекта:

- `index.html`
- `style.css`
- `script.js`

Страница открывается локально через `index.html` и показывает основной интерфейс на русском языке:

- верхнюю панель с названием, текущей датой, кнопкой `+`, переключателем темы и меню настроек;
- главный блок `Сегодня`;
- блок `Эта неделя`;
- блок `Просроченные`;
- блок `Планы / Идеи`;
- общий фильтр по категории и приоритету;
- пустые состояния для всех списков.

Реализованы светлая и темная темы без сохранения сложной логики задач.

### История выполнения

Статус: сделан.

Что сделано:

- создан `index.html` с основной структурой интерфейса;
- создан `style.css` со светлой и темной темой;
- создан `script.js` с установкой текущей даты, переключением темы и открытием меню настроек;
- добавлены верхняя панель, кнопка `+`, переключатель темы, меню настроек, общий фильтр, блоки `Сегодня`, `Эта неделя`, `Просроченные`, `Планы / Идеи`;
- добавлены пустые состояния и счетчики-заглушки;
- для SVG-кнопок добавлены `aria-label` и `title`.

Нюансы:

- логика задач, `localStorage`, формы добавления и реальные действия меню пока не реализованы, это следующие шаги плана;
- Playwright-браузерный бинарник в окружении не установлен, поэтому полноценную автоматическую проверку в настоящем браузере на этом шаге заменить удалось только проверками HTML, JS-синтаксиса и JS-поведения через мок DOM;
- визуальная оценка спокойности дизайна, удобства расположения блоков и читаемости остается ручной проверкой пользователя.

Правка после ручной проверки:

- меню с действиями `Экспорт данных`, `Импорт данных`, `Очистить завершенные`, `Сбросить все данные` больше не позиционируется поверх фильтров;
- кнопка настроек получила текст `Настройки`;
- раскрытое меню настроек стало частью верхней панели и сдвигает контент вниз, а не перекрывает его.

### Автопроверка

Проверить:

- существуют ровно нужные файлы проекта;
- `index.html` подключает `style.css` и `script.js`;
- страница открывается без ошибок JavaScript в консоли;
- все основные блоки присутствуют в DOM;
- все основные тексты интерфейса на русском языке;
- переключение темы меняет класс/атрибут темы на странице;
- интерактивные элементы доступны с клавиатуры;
- у SVG-кнопок, если они используются, есть `aria-label` и `title`.

### Ручная проверка

Проверить глазами:

- выглядит ли интерфейс спокойно, современно и не слишком ярко;
- действительно ли блок `Сегодня` воспринимается главным;
- удобно ли расположены `Эта неделя`, `Просроченные` и `Планы / Идеи`;
- не перегружены ли карточки и верхняя панель.

## Шаг 3. Создание, редактирование и базовые действия с задачами - сделан

### Готовый результат

Пользователь может:

- нажать `+` и открыть форму добавления;
- быстро создать задачу только с названием;
- создать задачу с датой, временем, категорией, приоритетом и повтором;
- создать задачу без даты, которая попадет в `Планы / Идеи`;
- редактировать задачу прямо на карточке;
- выполнить задачу;
- отменить выполнение в течение 8 секунд;
- отменить задачу через статус `cancelled`;
- удалить задачу с подтверждением;
- очистить завершенные задачи с подтверждением.

Реализована валидация:

- обязательное поле только название;
- название обрезается от лишних пробелов;
- максимум 120 символов для названия;
- максимум 1000 символов для описания;
- время нельзя задать без даты срока или даты планирования;
- дата в прошлом сохраняется без предупреждения.

### История выполнения

Статус: сделан.

Что сделано:

- добавлена скрытая форма создания задачи, которая открывается по кнопке `+`;
- реализовано быстрое создание задачи только с названием;
- добавлены поля формы: название, описание, срок, дата планирования, время, категория, приоритет, повтор;
- реализована валидация названия, длины описания и запрет времени без даты;
- задача с датой в прошлом сохраняется без предупреждения и отображается в `Просроченные`;
- задачи без срока и даты планирования отображаются в `Планы / Идеи`;
- задачи на сегодня отображаются в `Сегодня`;
- добавлено редактирование прямо на карточке;
- добавлены действия `Выполнить`, `Отменить задачу`, `Редактировать`, `Удалить`;
- после выполнения задача скрывается, появляется действие `Отменить` на 8 секунд;
- отмена выполнения возвращает задачу в `active`;
- отмена задачи переводит ее в `cancelled` и скрывает;
- удаление задачи требует подтверждения;
- действие `Очистить завершенные` удаляет задачи со статусами `completed` и `cancelled` после подтверждения;
- все изменения сохраняются в `localStorage`;
- карточки получили базовые метки категории, приоритета, срока, времени и повтора.

Автопроверки выполнены:

- проверен синтаксис `script.js`;
- в headless Edge проверен первый запуск с демо-задачами;
- проверено быстрое создание задачи только с названием;

## Шаг 4. Правила отображения, сортировка, фильтры и перенос - сделан

### Готовый результат

Реализованы правила отображения:

- `Сегодня` показывает активные задачи с `myDayDate` на текущую дату;

- `Планы / Идеи` показывает активные задачи без `dueDate` и без `myDayDate`;
- просроченные задачи не дублируются в других блоках;
- просрочка считается по дате, а не по времени;
- задачи с временем сортируются по времени;
- задачи без времени сортируются вручную по `order`;
- общий фильтр по категории и приоритету работает для всего экрана;
- счетчики обновляются после изменений;
- ручной перенос меняет `myDayDate`, а `Изменить срок` меняет `dueDate`.
